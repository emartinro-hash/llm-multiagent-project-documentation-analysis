# Resultado demo de ejemplo

## Pregunta

Resume el estado actual del proyecto, los riesgos abiertos, las dependencias críticas y el impacto de la factura pendiente.

## Respuesta esperada

El sistema debe recuperar información de las actas de seguimiento, el registro de riesgos, las incidencias, el presupuesto y las facturas simuladas. A partir de esa evidencia, debe generar una síntesis ejecutiva orientada a PMO que incluya:

- estado general del proyecto;
- riesgos abiertos;
- dependencias críticas;
- impacto económico o de plazo;
- limitaciones de la evidencia disponible;
- fuentes documentales utilizadas.

## Observación

Este ejemplo sirve para validar que el sistema no se limita a responder con conocimiento general, sino que utiliza el corpus documental proporcionado.
