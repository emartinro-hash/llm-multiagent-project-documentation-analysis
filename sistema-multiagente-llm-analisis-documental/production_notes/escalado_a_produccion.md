# Escalado a producción

La prueba de concepto puede evolucionar hacia un producto mínimo viable incorporando:

- autenticación de usuarios;
- control de acceso por roles;
- base vectorial persistente;
- monitorización de consultas;
- trazabilidad de fuentes;
- evaluación automática de respuestas;
- integración con gestores documentales corporativos;
- despliegue en VPS o infraestructura cloud;
- posible migración parcial a Python, FastAPI o LangGraph para obtener mayor control técnico.
