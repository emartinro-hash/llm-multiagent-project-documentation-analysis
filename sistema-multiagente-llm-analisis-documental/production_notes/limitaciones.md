# Limitaciones

El prototipo presenta varias limitaciones:

- depende de la calidad del corpus documental;
- puede recuperar evidencia incompleta;
- los resultados dependen del modelo LLM utilizado;
- Flowise facilita el prototipado, pero ofrece menos control fino que una arquitectura programática;
- no incorpora todavía autenticación, monitorización avanzada ni evaluación automática;
- no debe utilizarse como sistema productivo sin supervisión humana.
